The enqueue guard now accepts a cross-repository issue reference, `Fixes owner/repo#<n>`, next to the bare `Fixes #<n>` it already knew ([#809](https://github.com/ThinkFlowLab/FlyBot/issues/809)). Pull requests are opened in the code fork while issues stay upstream, so the bare spelling there points at a number the fork does not have; every such pull request was refused at the last step before the queue. The refusal text now names both spellings.
